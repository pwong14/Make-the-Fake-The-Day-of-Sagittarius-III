# The Day of Sagittarius III

This project is a fan-made tribute to the anime *The Melancholy of Haruhi Suzumiya*. Built with the Phaser game framework, the game reimagines key visual and narrative elements from the game shown in the anime into an interactive space battle simulation.

---

## Overview

In *The Day of Sagittarius III*, players command a fleet in a space battle environment. The game incorporates design elements inspired by the anime, that reference the original material.

The game is structured into multiple scenes:
- **Menu Scene:** A starting point with navigation options.
- **Tutorial Scene:** Instructions on controls and gameplay mechanics.
- **Play Scene:** The main gameplay area where strategic combat occurs.
- **End Scene:** A concluding scene that displays results and offers navigation options.

## Technical Details

This project makes use of several key components provided by the Phaser framework:

- **Arcade Physics System:**  
  Handles collision detection and movement, ensuring realistic interactions between ships during combat.

- **Cameras:**  
  Implements multiple camera views:
  - **Main Camera:** Focuses on the gameplay area.
  - **UI Camera:** Displays heads-up display (HUD) elements.
  - **Minimap Camera:** Provides an overview of the battlefield.

- **Text Objects:**  
  Used to display game titles, instructions, and in-game status updates.

- **Tween Manager:**  
  Creates smooth animations for bullet trajectories, explosions, and transitions, enhancing the visual experience.

- **Timers:**  
  Schedules recurring events such as enemy AI updates and combat checks, keeping gameplay dynamic.

- **Character portraits and voicing:**  
  Displays character models and plays iconic character voice lines for immersion purposes.
